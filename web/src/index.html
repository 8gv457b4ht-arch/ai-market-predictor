Start the predictor

Press Start and this page connects directly from your browser to the public market data of Binance, Bybit and OKX. No account or key is needed for prices, candles, trades and order books.

The first model is trained on real price history in your browser. It takes about a minute. Predictions, models and results are stored in this browser.

Optional: add an Anthropic API key in Settings for AI news analysis.
