# Управление фоновым процессом (без секретов)

Файлы этой папки читает каждый запуск бэкенда. Чтобы включить, скопируйте пример без `.example`:

- `notify.json` — условия уведомлений (см. `notify.example.json`). Токены ntfy/Telegram — только в Secrets.
- `commands.json` — разовые команды: откат модели, восстановление базы, внеплановая копия (см. `commands.example.json`).
  Каждый `id` выполняется один раз; для повтора задайте новый `id`.
